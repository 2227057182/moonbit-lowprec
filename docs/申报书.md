# moonbit-lowprec 项目申报书

## 一、项目定位

MoonBit 有单精度和双精度浮点，没有低精度数值层。本项目提供 binary16、bfloat16、定点与仿射量化四类表示，并给出 16 位浮点的加减乘除，再读取 GGUF 容器把真实量化权重还原成数值。全部以位模式存储，转换与运算按 IEEE 754 和量化规范定义，验证用穷举而不是抽样。

## 二、为什么需要

2026-11-26 查询 mooncakes.io 全部 3975 个模块描述，`fixed point`、`int16`、`f16`、`fp16`、`bfloat16` 均无匹配；描述之外另做了源码复检：`matrixlt/moon-onnx` 的 `ml_kernels/quant` 确有 per-tensor 的 int8 与 uint8 仿射量化，按 QuantizeLinear 规范并含银行家舍入，但它没有 float16、bfloat16、逐通道参数、重量化，也不对外暴露类型。其余邻近项目（任意精度与区间、IEEE 浮点仿真、GGUF 容器读取）各覆盖别的范围，都不提供类型层。

能存不能算的表不是数值层：上述项目没有一个给出可相加、可相除且正确舍入的 16 位浮点值。本版因此把主要工作放在有效数上的算术。

## 三、实现内容

1. 16 位浮点运算：F16 与 BF16 各有加、减、乘、除。操作数解包成整数有效数与二进制指数，在 64 位内精确组合，只在落地时舍入一次：就近偶数、渐进下溢、溢出到无穷、NaN 与无穷传播、`(-0)+(-0)` 保号都按标准。全程不用浮点指令。
2. F16：位模式存取、字段访问、分类判定；扩展到单精度对全部位模式精确，窄化就近偶数，溢出到无穷，下溢渐进到次正规再归零。
3. BF16：指数 8 位、尾数 7 位。扩展只是左移 16 位；窄化提供就近偶数与截断，截断时 NaN 载荷若落在被丢的低半部会重置 quiet 位。
4. Fixed：`raw * 2^-frac` 存于 width 位字段；五种舍入、两种溢出，舍入在幅值上定义再恢复符号。
5. 量化：仿射与逐通道参数、量化与反量化、整数乘法因子加右移的重量化、64 位整数点积。
6. GGUF：解析 v3 容器头，跳过元数据但保留 `general.alignment`；另有只读 24 字节前缀的入口，用于拿到载荷之前识别文件。F32、Q4_0、Q5_0、Q8_0 都还原成数值：每 32 权重一块，块长 18、22、34 字节，Q5_0 的第 5 位另存 4 字节，权重 j 与 j+16 各取一位。

## 四、验证

`moon test` 共 64 项，wasm、wasm-gc、js 三后端全通过。

- binary16、bfloat16 各自全部 65536 位模式往返，分别检查 63490 与 65282 个非 NaN 值，0 处不符。
- 算术：每种格式 65536 个位模式 × 12 个探针，四个运算合计 3145728 个结果对更高精度路径，0 处不符。
- 参考表：每种格式 171 对操作数 × 4 个运算，由有理数精确生成并一次舍入；binary16 的 684 个结果与 numpy float16 完全一致。
- 定点乘法 65536 操作数对 × 5 种舍入 = 327680 个结果对独立 Double 参考；16 位字段饱和与回绕各 65536 个原始值。
- 重量化 256 个 int8 码对 Double 比对；舍入界 990 个点；参考向量 60 条由 verify 校验。
- GGUF：真实模型 stories260K（sha256 270cba1b…，48 张量、19 元数据、载荷起点 14176）的头部解出与 llama.cpp 相同的值；576 字节容器含四种张量，解析与反量化逐值断言，块内每个权重都能手算；非容器与截断载荷都必须被拒。

整数路径与 Double 路径互证，不一致抓到两个真缺陷：`(-0)+(-0)` 丢符号；bfloat16 极值相加因 126 位移位静默归零，据此加了「指数差超过 50 位时小者不足半个 ulp」的判据。

## 五、可检查性

```
moon run cmd/main -- f16 0x0002
bits=2 sign=0 exp=0 mant=2 class=subnormal value=1.1920929e-7
```

report 把同一段 256 点正弦放进四种舍入模式：就近偶数 49.65 dB，截断 43.7 到 44.3 dB。gguf 走完整链路：反量化、重新定标到 int8、算 SNR。

arith f16 0x3C00 0x4200 给出 0x4400、0xc000、0x4200、0x3555，都能手算核对。

## 六、边界与限制

Int 在本方言中是 32 位有符号数。定点乘法限定字段不超过 16 位；更宽累加走 mul_raw 或 64 位点积；重量化乘积约 2^38，先在 Int64 里形成再取整。算术核心在 64 位内完成，但 bfloat16 指数跨度超出可对齐范围，超过 50 位差按「小者不足半个 ulp」处理。

不覆盖 e4m3 这类非 IEEE 8 位浮点、任意精度、低精度超越函数。
