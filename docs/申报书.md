# moonbit-lowprec 项目申报书

## 一、项目定位

MoonBit 有单精度和双精度浮点，没有低精度数值层。本项目提供 binary16、bfloat16、定点、仿射量化与 8 位浮点五类表示，给出 16 位浮点的加减乘除，再读取 GGUF 容器把真实量化权重还原成数值。全部以位模式存储，转换与运算按 IEEE 754、OCP FP8 与量化规范定义，验证用穷举。

## 二、为什么需要

查 mooncakes.io 全部 3975 个模块描述，`fixed point`、`int16`、`f16`、`fp16`、`bfloat16`、`float8` 均无匹配；复检源码：`matrixlt/moon-onnx` 的 `ml_kernels/quant` 有 per-tensor 的 int8/uint8 仿射量化（QuantizeLinear 规范、银行家舍入），但无 16 位浮点、逐通道参数、重量化，也不暴露类型；其余邻近项目各覆盖别的范围。

能存不能算的表不是数值层：上述项目没有一个给出可加减乘除且正确舍入的 16 位浮点值，本版因此把工作放在有效数上的算术。`soehi/gguf` 0.1.3 已把 Q4_K、Q6_K 还原为 Float，本项目补 Q5_K 并统一输出 Double，接同一套报告。

## 三、实现内容

1. 16 位浮点运算：F16 与 BF16 各有加减乘除。操作数解包为整数有效数与指数，在 64 位内精确组合，落地只舍入一次，按标准处理下溢、溢出、NaN 与 `(-0)+(-0)` 保号，全程不用浮点指令。
2. F16：位模式、字段与分类；扩展精确，窄化就近偶数，溢出到无穷，下溢渐进。
3. BF16：指数 8 位、尾数 7 位。扩展即左移 16 位；窄化提供就近偶数与截断，截断时被丢低半部含 NaN 载荷则重置 quiet 位。
4. Fixed：`raw * 2^-frac` 存于 width 位字段；五种舍入、两种溢出，舍入在幅值上定义再恢复符号。
5. 量化：仿射与逐通道参数、量化与反量化、整数乘法因子加右移的重量化、64 位整数点积。
6. GGUF：解析 v3 容器头，跳过元数据但保留 `general.alignment`；另有只读 24 字节前缀的入口。F32、Q4_0、Q5_0、Q8_0、Q4_K、Q5_K、Q6_K 都还原成数值：前者每 32 权重一块（18、22、34 字节），K-quant 每 256 权重一超块（144、176、210 字节），12 字节装 8 个 6 位尺度与 8 个最小值、高 2 位藏在相邻字节，Q5_K 的第 5 位散在 32 个共享字节。
7. FP8：E4M3 与 E5M2 的位模式、字段与判定；扩展精确，窄化就近偶数、渐进下溢。E4M3 无无穷，448 与 NaN 共用全 1 指数，溢出按饱和或转 NaN 两种约定。

## 四、验证

`moon test` 共 76 项，wasm、wasm-gc、js 三后端全通过。

- binary16、bfloat16 各自全部 65536 位模式往返，分别检查 63490 与 65282 个非 NaN 值，0 处不符。
- 算术：每种格式 65536 个位模式 × 12 个探针，四个运算合计 3145728 个结果对更高精度路径，0 处不符。
- 参考表：每种格式 171 对操作数 × 4 个运算，由有理数精确生成并一次舍入；binary16 的 684 个结果与 numpy float16 完全一致。
- 定点：65536 操作数对 × 5 种舍入 = 327680 个结果对 Double 参考，饱和与回绕各 65536 个原始值；重量化 256 个 int8 码对 Double 比对，舍入界 990 点，参考向量 60 条。
- GGUF：真实模型 stories260K（48 张量、19 元数据、载荷起点 14176）头部与 llama.cpp 相同；1264 字节容器含七种张量，逐值断言；三种 K-quant 各 256 值经官方 gguf 包比对完全一致；非容器与截断载荷被拒。
- FP8：两格式各 256 位模式对有理数表逐值一致，NaN 与无穷标记相符；每个有限模式窄化回原位模式；正半轴随位模式严格递增。

整数与 Double 双路互证，抓到两个真缺陷：`(-0)+(-0)` 丢符号；bfloat16 极值相加因移位归零。

## 五、可检查性

`moon run cmd/main -- f16 0x0002` 给出 subnormal 与 1.1920929e-7。
report 把 256 点正弦放进四种舍入：就近偶数 49.65 dB，截断 43.7 到 44.3 dB；gguf 走反量化、重量化到 int8、算 SNR 全链路。

arith f16 0x3C00 0x4200 给出 0x4400、0xc000、0x4200、0x3555，可手算核对。

## 六、边界与限制

Int 为 32 位有符号数：定点乘法字段不超过 16 位，更宽累加走 mul_raw 或 64 位点积；重量化乘积约 2^38，先在 Int64 形成再取整；bfloat16 指数跨度超出可对齐范围，超过 50 位差按「小者不足半个 ulp」处理。

不覆盖任意精度、低精度超越函数；FP8 只做存储、判定与转换，不做乘加。
