# moonbit-lowprec 项目申报书

## 一、项目定位

MoonBit 有单双精度浮点，没有低精度数值层。本项目提供 binary16、bfloat16、定点、仿射量化与 8 位浮点五类表示，给出 16 位浮点的加减乘除，各格式可直接互转，再读取 GGUF 容器把真实量化权重还原成数值。全部以位模式存储，按 IEEE 754、OCP FP8 与量化规范定义。

## 二、为什么需要

查 mooncakes.io 3975 个描述，`fixed point`、`int16`、`f16`、`fp16`、`bfloat16`、`float8` 均无匹配；复检源码：`matrixlt/moon-onnx` 的 `ml_kernels/quant` 有 per-tensor 的 int8/uint8 仿射量化（银行家舍入），但无 16 位浮点、逐通道参数与重量化，不暴露类型；其余邻近项目覆盖别的范围。

没有项目给出可加减乘除且正确舍入的 16 位浮点值。`soehi/gguf` 0.1.3 已把 Q4_K、Q6_K 还原为 Float，本项目补 Q2_K、Q3_K、Q5_K 并统一输出 Double。

## 三、实现内容

1. 16 位浮点运算：F16 与 BF16 各有加减乘除。解包为整数有效数与指数，64 位内精确组合，只舍入一次，按下溢、溢出、NaN、`(-0)+(-0)` 保号，不用浮点指令。
2. F16：位模式、字段与分类；扩展精确，窄化就近偶数，溢出无穷，下溢渐进。
3. BF16：指数 8 位、尾数 7 位。扩展即左移 16 位；窄化提供就近偶数与截断，截断时含 NaN 载荷则重置 quiet 位。
4. Fixed：`raw * 2^-frac` 存于 width 位；五种舍入、两种溢出。
5. 量化：仿射与逐通道参数、量化与反量化、乘法因子加右移的重量化、64 位点积。
6. GGUF：解析 v3 容器头与 24 字节前缀，跳过元数据保留 `general.alignment`。F32、Q4_0、Q5_0、Q8_0 与 Q2_K 到 Q6_K 五种超块都还原成数值：前者每 32 权重一块（18、22、34），后者每 256 权重一超块（84、110、144、176、210），Q2_K 两位、Q3_K 三位并借掩码反转偏移，Q5_K 第 5 位散在共享字节。写入侧 build_gguf 定偏移，附 Q8_0/Q4_0 量化器。
7. FP8：E4M3 与 E5M2 的位模式与判定；扩展精确，窄化就近偶数、渐进下溢。E4M3 无无穷，448 与 NaN 共用全 1 指数，溢出饱和或 NaN。
8. 互转：bf16↔f16、FP8→f16、e4m3↔e5m2 六方向，位模式上移位换基，不经单精度，舍入一次；bf16→f16 有效数位够用而精确，越界进无穷或归零。

## 四、验证

`moon test` 共 88 项，wasm、wasm-gc、js 三后端全通过。

- binary16、bfloat16 各自全部 65536 位模式往返，分别检查 63490 与 65282 个非 NaN 值。
- 算术：每格式 65536 位模式 × 12 探针，四运算合计 3145728 结果对高精度路径，0 处不符。
- 参考表：每格式 171 对操作数 × 4 运算，有理数精确生成一次舍入；binary16 的 684 结果与 numpy float16 一致。
- 定点：65536 操作数对 × 5 舍入 = 327680 结果对 Double，饱和与回绕各 65536，重量化 256 个 int8 码比对，舍入界 990 点，参考向量 60 条。
- GGUF：真实模型 stories260K（48 张量、起点 14176）头部与 llama.cpp 相同；1554 字节容器含九种张量，逐值断言；五种 K-quant 各 256 值经官方 gguf 包比对完全一致；非容器与截断载荷被拒；自建 210 字节容器经官方包读回，误差 0.00390625 与 0.0625。
- FP8：两格式各 256 位模式对有理数表逐值一致，NaN 与无穷标记相符；每个有限模式窄化回原位模式；正半轴随位模式单调。
- 互转：bf16、f16 全 65536 位模式对 Double 路径，bf16 正半轴 0 回退；FP8 四向各 256 位模式；bf16→f16 溢出 28674、归零 26112，e5m2→e4m3 饱和 60。

整数与 Double 互证，抓到三个真缺陷：`(-0)+(-0)` 丢符号；bfloat16 极值相加移位归零；64 位右移按位宽取模，bf16 极小值误判为 f16 次正规。

## 五、可检查性

`moon run cmd/main -- f16 0x0002` 给出 subnormal 与 1.1920929e-7。
report 把 256 点正弦放进四种舍入：就近偶数 49.65 dB，截断 43.7 到 44.3 dB；gguf 走反量化、重量化、SNR。
convert bf16 f16 0x3F80 给出 0x3C00；emit-gguf 打印容器 hex。

## 六、边界与限制

Int 为 32 位：定点乘法字段不超过 16 位，更宽累加走 mul_raw 或 64 位点积；重量化乘积约 2^38 在 Int64 形成；bfloat16 指数跨度过大，超 50 位差按小者不足半个 ulp。

不覆盖任意精度、低精度超越函数；FP8 只做存储、判定与转换，不做乘加。写入无元数据与 K-quant 载荷。
